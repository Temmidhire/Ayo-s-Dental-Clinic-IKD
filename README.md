# Temmidhire GitHub Pages Portfolio

Static recreation of the Carrd landing page for Temidire Ogunbekun.

## Deploy

1. Create/open the repository used for `temmidhire.github.io`.
2. Copy `index.html` and `style.css` into the repository root.
3. Commit and push.
4. In GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.
5. Your site will be available at:
   https://temmidhire.github.io/

## Before publishing

The Carrd page contains four project entries. The first and third links have been connected here to the known GitHub Pages project paths. The Aquaponics and COVID-19 project buttons are intentionally inactive until their exact destination URLs are supplied, so the site does not invent links.
