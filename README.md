# Family Dental Clinic Website

A static, GitHub Pages-ready website for a family-owned dental clinic in Ikorodu, Lagos.

## Important
This version is intentionally a **pre-reopening/staging website**. It does not claim that the clinic is currently open and contains no patient records.

Replace the placeholder:
- clinic name
- phone number
- WhatsApp number
- email
- exact address
- services (if different)
- dentist/team information

## Deployment
1. Create a public GitHub repository, e.g. `family-dental-clinic`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save.
6. GitHub will provide a free `github.io` address.

Do NOT upload the real 5,000-patient Excel file or any identifiable patient information to this repository.
